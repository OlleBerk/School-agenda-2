      Rekenhulp — abc-formule

      Los ax² + bx + c = 0 op.

      Hoe werkt dit?
      Discriminant D = b² − 4ac.
      Is D > 0: twee oplossingen, x = (−b ± √D) / (2a).
      Is D = 0: één oplossing, x = −b / (2a).
      Is D < 0: geen reële oplossingen.
